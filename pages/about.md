# About me

<div class="profile-intro" markdown="1">

<div class="profile-intro-text" markdown="1">

I'm a staff technical writer with 14 years of experience building developer documentation, API references, and scalable knowledge systems for engineering organizations at Squarespace, Attentive, Vistar Media, AppDirect, and Google.

I set documentation standards, coach engineering teams, and own docs-as-code platforms. Lately, I've been building AI-powered content workflows with tools like Claude, Codex, Cursor, and Model Context Protocol (MCP) integrations.

My work combines technical writing with engineering enablement, information architecture, and process development, all with the same goal: make complex systems easier to understand, document, and maintain.
